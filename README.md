# 饭堂销量预测

使用 [t0-beta](https://huggingface.co/theforecastingcompany/t0-beta) 预测每个饭堂餐段工作表的各项。“当周的第几天”和“是否工作日”作为已知未来协变量。

```powershell
uv run python main.py
```

默认读取 `./饭堂销量样例_2026-08-01至09-30.xlsx`，生成 `./饭堂销量预测_未来7天.xlsx`。原始工作簿不会被覆盖；每个工作表末尾会追加未来 7 天的预测行，并以浅蓝色填充整行。每一个菜品列都会单独预测，“每日总销量”由预测菜品销量自动求和。

“是否工作日”由中国法定工作日历生成，包含周末、法定节假日与调休。生产运行可通过 `--input`、`--output`、`--days` 和 `--device` 配置。首次运行会下载模型权重。
